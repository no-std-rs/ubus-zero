# Code of conduct

This project is committed to a respectful, harassment-free community.

Be constructive, assume good intent, discuss the work rather than the person,
and make room for people with different backgrounds and levels of experience.
Harassment, threats, discriminatory language, and sustained disruption are not
acceptable in project spaces.

Report conduct concerns privately through the repository owner's GitHub
profile. Maintainers may edit or remove contributions, limit participation, or
take other proportionate action to protect the community.
